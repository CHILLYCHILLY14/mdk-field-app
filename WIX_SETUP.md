# Add MDK Field App to Wix

## Recommended mobile setup

Use a prominent Wix button such as **Open MDK Field App** and link it to:

`https://CHILLYCHILLY14.github.io/mdk-field-app/`

Set the link to open in a new tab. This gives the app the full phone screen and provides the most reliable PDF download, share sheet, keyboard, and Add to Home Screen behavior.

## Embed inside a Wix page

1. In the Wix editor, choose **Add Elements → Embed Code → Embed a Site**.
2. Enter the GitHub Pages URL above.
3. Stretch the embed to the full available width.
4. Use a height of at least `800px` on desktop and `720px` on mobile.
5. Preview both breakpoints and publish.

Some mobile browsers restrict file sharing inside an embedded frame. Keep an **Open full screen** button beside the embed so staff can use PDF sharing without that restriction.

## Suggested Wix layout

- Page title: **MDK Field App**
- One short line: **Create work orders, timesheets, and quotes from the field.**
- Primary button: **Open full screen**
- Embedded app underneath for desktop convenience

## Adding to a phone home screen

### iPhone / iPad

Open the full-screen URL in Safari, tap **Share**, then **Add to Home Screen**.

### Android

Open the URL in Chrome, open the menu, then tap **Install app** or **Add to Home screen**.

## Data handling reminder

Each browser/device has its own saved records. Use **More → Export full backup** regularly and before changing devices. Import that JSON backup on the replacement device.
